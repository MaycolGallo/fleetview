# **App Name**: FleetView

## Core Features:

- Vehicle Map Display: Display multiple vehicle pins on a map using `@vis.gl/react-google-maps`.
- Vehicle Pin Details: Clicking a vehicle pin should open a dialog with detailed vehicle information.
- Dynamic Vehicle Updates: Update vehicle positions in real-time on the map.
- Vehicle Filtering: Filter vehicles by their status (e.g., active, idle, out-of-service).
- Vehicle Telemetry Simulation: Create mock vehicle telemetry data

## Style Guidelines:

- Primary color: Deep dark blue (#1A237E) to provide a professional feel.
- Background color: Desaturated dark blue (#283593) for the interface background.
- Accent color: Amber (#FFC107) used for highlighting vehicle statuses.
- Body and headline font: 'Inter', a sans-serif for clear readability on interactive map interfaces.
- Simple, scalable vector icons to represent different vehicle types and statuses.
- Clean, minimalist layout with clear visual hierarchy for vehicle information and controls.
- Subtle transitions for map updates and vehicle movements.
